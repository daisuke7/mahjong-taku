# docs/ の読み方

このフォルダは「作者がコードを読まない完全バイブコーディングでどこまで作れるか」という実験の
記録そのものです。アプリ本体より、ここに残した方針・失敗・設計判断の方が、このリポジトリの本命です。
各文書は書いた当時の判断をそのまま残し、後から分かったことは日付付きの追記で重ねています
(書き直して整合させることはしていません。判断の変遷も記録のうちです)。

## まず読むもの(実験の枠組み)

| 文書 | 内容 |
|---|---|
| [development-policy.md](development-policy.md) | 実験の枠組みと優先順位。作者はコードを読まない・git は使わない(2026-11-09 に初回 push で方針変更)・他人の意見は聞かない、の 3 つの縛りと、その中で「テストだけは必須」とした理由 |
| [failure-log.md](failure-log.md) | 失敗談集。逐次ログではなく「何が起きて・どう気づいて・何を変えたか」が語れる失敗だけを厳選。**「どう気づいたか」= 検知網の記録**が、この実験の観測データ |
| [vibe-coding-safety-layers.md](vibe-coding-safety-layers.md) | 人がコードを読まない前提で安全性を保つ 5 つの層(機械強制 / 独立検証エージェント / 実行可能な仕様 / 置き場所の登録簿 / 本番検知)を、このプロジェクトの対応状況と、業務で同じことをやる場合の方法に分けて整理 |
| [audit-log.md](audit-log.md) | 二重実装監査の実施記録。「同じ値を出している間は誰も気づかない」型の負債を、テスト件数 +50 または 60 日の機械的な条件で定期的に拾う運用 |
